A small open model that writes and repairs Flisk config files, tested against Flisk's own validator. It is in private beta while we move it to a proper server. You can run the same model on your own computer today.

Run it yourself See the test results
You ask
Write a Flisk service.json for a worker called emailer in the shop stack.
You get
{
  "schemaVersion": 1,
  "appName": "emailer",
  "appType": "worker",
  "stack": "shop"
}

A real answer from the model. It passes the Flisk validator.

Run it on your computer

The model is a prompted qwen2.5-coder:7b with Flisk's rules. With Ollama installed, two commands give you the same OpenAI-compatible API on localhost:11434/v1:

curl -fsSLO https://raw.githubusercontent.com/flisk-sh/flisk-inference/main/deploy/Modelfile
ollama pull qwen2.5-coder:7b && ollama create flisk-wolf -f Modelfile
